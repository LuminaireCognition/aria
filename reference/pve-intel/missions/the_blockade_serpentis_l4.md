## Waves/Rooms

Single ungated pocket. Fleet warp at preferred distance is possible.

### Initial Defenders (28-30km)
- 1x Sentry Stasis Tower
- 3-4x Destroyer Corelior Sentinel/Cannoneer
- 4-5x Battleship Core Admiral **[Trigger - spawns Wave 1]**

### Wave 1 (45-85km)
- 3x Destroyer Corelior Trooper/Cannoneer
- 9-10x Elite Cruiser Core Corelium Guardian Chief (sensor damp)
- 3x Battlecruiser Corelatis Platoon Leader/Captain
- 5x Battleship Core Admiral **[Trigger - spawns Wave 2]**

### Wave 2 (50-90km)
- 2x Elite Frigate Coreli Guardian Patroller
- 1x Destroyer Corelior Sentinel
- 3-5x Battleship Core Admiral/Vice Admiral **[Trigger - spawns Wave 3]**

### Wave 3 (70-90km)
- 2x Elite Frigate Coreli Guardian Patroller
- 2x Destroyer Corelior Sentinel
- 4-5x Battleship Core Admiral **[Trigger - spawns Wave 4]**

### Wave 4 (70-90km)
- 2x Elite Frigate Coreli Guardian Patroller
- 2x Elite Cruiser Corelum Guardian Chief Sentinel/Guard
- 5x Battleship Core Rear/High Admiral **[Trigger - spawns Wave 5]**

### Wave 5 - Final (70-90km)
- 2-4x Elite Frigate Coreli Guardian Watchman
- 4x Battleship Core Lord Admiral **(mission objective)**
- 0-1x Battleship Shadow Serpentis (rare, faction drops possible)

## Blitz
Kill trigger battleships in each wave to advance to Wave 5, then destroy the Core Lord Admirals.

## Tactical Notes
- **Sensor dampening is extremely heavy** in this variant. Wave 1 alone has 9-10 elite cruisers with damps.
- Fit a Sensor Booster and/or Signal Amplifier to counter dampening.
- Auto-targeting missiles and drones work even when you cannot lock targets.
- Estimated bounties: ~19.5M ISK. Loot + Salvage: ~16.6M ISK.
