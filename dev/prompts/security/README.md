# Security Prompts

This directory contains meta-prompts and instructions for auditing, red-teaming, and hardening the codebase. These prompts are designed to be used by AI agents acting in security engineering roles.

## Contents

| File | Purpose |
|------|---------|
| `audit_ai.md` | Comprehensive security review focusing on prompt injection, agent misuse, and Python service risks |
| `supply_chain_and_dependencies.md` | Dependency management, lockfile integrity, licensing compliance, and supply chain risk |
